## Risks & open questions
1. **Ortam (R-13) — bu makine hiçbir profili çalıştıramaz.** `doctor`: check.conf'ta henüz
   `requires` yok; planlanan `requires typecheck: Node >= 24.15` bu makinede **karşılanmıyor**:
   Node **v21.6.2** (LTS değil). vitest 5.1 Node `^22.12 || ^24 || >=26`, jsdom 31 Node
   `^22.22.2 || ^24.15 || >=26` istiyor. Verdict: fast **not runnable**, full **not runnable**
   (npm ping: OK). Ayrıca güncel durum: Node **26 (Lithium) Active LTS** (26.13.1), 24 (Krypton)
   bakım LTS'inde (24.22.3) — bootstrap'te "Node 24 LTS" yazdım, o bilgi eskimiş.
   **Önerim:** ortamı düzeltin ve **Node 26 LTS**'e geçelim (`docs/conventions.md` güncellenir;
   tüm seçili paketler `>=26` destekliyor; destek süresi 24'ten uzun). Kurulum sizin işiniz
   (sistem değişikliği): `! winget install OpenJS.NodeJS.LTS` (26.x kurar), sonra yeni terminal.
   `requires`: Node major ≥ 26. CI aynı sürümü kullanır. Alternatif: Node 24.22.3'te kalmak.
   **Karar (plan onayı):** Node 26 LTS. Onay anında ortam düzeltildi: Node **v26.13.1** kuruldu →
   beklenen verdict fast **runnable**, full **runnable** (`requires` adım 1'de eklenir, doctor ile doğrulanır).
2. **Spec boşluğu (R-10): büyük "İ".** Türkçe klavyede Shift+i "İ" üretir; spec yalnızca
   `i`/`ı` → `I` diyor, yani "34 İAB 12" AC-6'ya göre **reddedilir** — niyete aykırı.
   **Önerim:** spec revizyonu (R-08): R-3 ve AC-7'ye "`İ` de `I` olur" eklenir (ör. "34 İab 12"
   → "34IAB12"); Scorecard'da Spec revisions = 1. **Karar:** kabul — spec revize edildi.
3. **Aynı milisaniyede iki kayıt** sıralamayı belirsiz bırakabilir. "Kaydet" kayıt sürerken
   kapalı (AC-3) olduğundan kullanıcıyla olamaz; testte saat sahte ve artan. Önerim: ek önlem yok.
4. **`TZ` Windows'ta.** Node'un Git Bash altında `TZ=Europe/Istanbul`'u uyguladığı adım 1'de
